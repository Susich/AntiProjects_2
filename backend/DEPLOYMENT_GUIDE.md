# 🚀 Пошаговое развёртывание бэкенда на Google Apps Script (Google Sheets)

Бэкенд хранит пользователей, комнаты, участников, расходы и статусы оплат в Google Таблице. Приложение синхронизируется с ней по HTTP: авторизация по телефону и паролю, вход в комнаты по коду, обновление статусов оплат каждые несколько секунд. Отдельный платный сервер не нужен.

---

### Шаг 1. Создание Google Таблицы
1. Перейдите в [Google Drive](https://drive.google.com/) под своим Google Аккаунтом.
2. Нажмите **«Создать» ➔ «Google Таблицы»** (Google Sheets).
3. Назовите таблицу, например: **`PartySplit Database`**.

Структуру вкладок вручную создавать не нужно: при первом запросе скрипт создаст листы `Users`, `Parties`, `PartyMembers`, `Expenses` и `PaymentStatuses` с нужными колонками.

---

### Шаг 2. Добавление скрипта
1. В верхнем меню таблицы нажмите: **«Расширения» (Extensions) ➔ «Apps Script»**.
2. Замените всё содержимое файла `Code.gs` кодом из [`backend/Code.gs`](./Code.gs).
3. Нажмите **«Сохранить»** (`Ctrl + S` / `Cmd + S`).

---

### Шаг 3. Публикация веб-приложения (Web App)
1. Нажмите **«Начать развертывание» (Deploy) ➔ «Новое развертывание» (New deployment)**.
2. Нажмите шестерёнку ⚙️ рядом с *«Выберите тип»* и выберите **«Веб-приложение» (Web app)**.
3. Заполните поля:
   - **Описание:** `PartySplit API v2 (batch + cache)`
   - **Выполнять от имени (Execute as):** `Меня (<ваш_email@gmail.com>)`
   - **У кого есть доступ (Who has access):** ⚠️ **`Все` (Anyone)** — иначе приложение не сможет отправить запрос без OAuth-логина.
4. Нажмите **«Развернуть» (Deploy)**.
5. При первом развёртывании Google запросит подтверждение прав:
   - **«Предоставить доступ»** → выберите аккаунт.
   - Если появится предупреждение «Google haven’t verified this app», нажмите **«Advanced»** → **«Go to PartySplit (unsafe)»** → **«Allow»**.

---

### Обновление уже развёрнутого бэкенда (важно!)

После обновления приложения нужно обновить и развёртывание: в актуальной версии появились регистрация, вход, токены сессии, подтверждение банка для комнаты, синхронизация статусов оплат, пакетный endpoint `batch`, серверный кэш и оптимизированные чтения.

1. Откройте таблицу → **«Расширения» → «Apps Script»**.
2. Замените содержимое `Code.gs` актуальным кодом из [`backend/Code.gs`](./Code.gs) и сохраните.
3. Нажмите **«Развернуть» (Deploy) → «Управление развертываниями» (Manage deployments)**.
4. Рядом с активным веб-приложением нажмите ✏️ **«Изменить» (Edit)**.
5. В поле **«Версия» (Version)** выберите **«Новая версия» (New version)** и нажмите **«Развернуть» (Deploy)**.
6. URL веб-приложения не меняется. В приложении откройте профиль → **«Комната и Google Sheets» → «Настройки»** и нажмите **«Проверить»**. Проверка требует API версии 2 и поддержки `batch` и покажет ошибку, если развёртывание старое.

> Без нового развёртывания сервер вернёт «Неизвестное действие» для `registerUser`, `loginUser`, `setTransferStatus`, `leaveParty` и других действий v2. Старые методы `syncPartyMembers` и `removePartyMember` удалены. Приложение сможет работать со старым URL: очередь записи автоматически переключится на отдельные запросы, но батчи, серверный кэш и ускоренные чтения не включатся до развёртывания новой версии.

> Проверить версию API можно запросом `GET <URL>?action=ping` или `POST {"action":"version"}`. `ping`/`version` не читают таблицу и не берут блокировку, поэтому подходят для health-check.

---

### Шаг 4. Подключение к приложению
1. Скопируйте **URL веб-приложения (Web app URL)** вида `https://script.google.com/macros/s/AKfycb.../exec`.
2. Откройте PartySplit:
   - **Профиль** → **«Комната и Google Sheets»** → вкладка **«Настройки»**.
   - Вставьте URL и нажмите **«Сохранить URL»**.
   - Нажмите **«Проверить»** — должно появиться сообщение об успешном подключении.
3. Зарегистрируйтесь, создайте комнату и передайте друзьям её код. При входе каждый участник подтверждает банк для этого сбора; в итогах получатель виден с банком и телефоном, а номер можно скопировать одной кнопкой. Платёжные ссылки и deep links не используются.
